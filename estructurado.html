🧩 Análisis Estructurado

El análisis estructurado es una metodología de ingeniería de software enfocada en definir con claridad qué debe hacer el sistema, los datos que maneja y cómo fluye la información entre procesos antes de pasar al diseño técnico o programación. Su paradigma se clasifica mediante el Modelo Esencial.

🧭 Modelo Esencial

Representa los requisitos fundamentales del sistema y las reglas del negocio sin atarse todavía a plataformas, lenguajes o hardware. Está constituido por el Modelo Ambiental y el Modelo de Comportamiento.

↑ Volver a los botones

🌍 Modelo Ambiental

Define la frontera exacta entre el sistema de Veterinaria Patitas Felices y su entorno externo (clientes, administrador, mascotas y servicios externos), precisando qué estímulos recibe y qué respuestas emite.

🎯 Declaración de Propósitos

Resume en una descripción concisa qué hace el sistema y para qué existe: permitir el registro de mascotas, la solicitud y control de citas veterinarias, la gestión de horarios y la comunicación directa con la clínica.

🗺️ Diagrama de Contexto

Representa todo el sistema como un único proceso central interactuando con actores externos como el Cliente (registra mascotas, pide citas, envía mensajes) y el Administrador (gestiona horarios, aprueba citas, lee mensajes).

📌 Lista de Acontecimientos

  • El cliente solicita registrarse o iniciar sesión en el sistema.
  • El cliente inscribe o elimina una mascota en su perfil.
  • El cliente solicita una cita eligiendo fecha, hora y servicio.
  • El cliente envía un mensaje o consulta a la veterinaria.
  • El administrador agrega/elimina horarios o confirma/rechaza citas.

⚙️ Modelo de Comportamiento

Detalla cómo se procesan, validan y almacenan los datos dentro del sistema para responder a los acontecimientos del entorno.

🔀 Diagrama de Flujo de Datos por Niveles

Organiza los procesos internos de forma jerárquica (Nivel 0, Nivel 1, etc.), mostrando cómo viajan los datos entre procesos (autenticación, gestión de mascotas, agenda de citas, mensajería) y almacenes de datos (usuarios, mascotas, citas, mensajes, config).

🗄️ Diagrama de Entidad y Relación

Modela las entidades clave y sus vínculos: un Usuario (Cliente) registra una o más Mascotas, solicita Citas sobre un horario y envía Mensajes, mientras el Administrador administra los Horarios y estados de las citas.
