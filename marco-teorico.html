📚 Marco Teórico

Fundamentos técnicos, arquitectura web y herramientas utilizadas en el desarrollo del sistema de gestión para Veterinaria Patitas Felices.

🌐 Arquitectura Web Cliente-Servidor

El sistema opera sobre una arquitectura web moderna desplegada mediante GitHub Pages, donde la interfaz en el navegador se comunica en tiempo real con servicios en la nube sin necesidad de administrar servidores propios.

  • Frontend: HTML5 semántico, CSS3 responsivo y JavaScript ES Modules.
  • Persistencia en la nube: Firebase Firestore para almacenamiento y sincronización en vivo.
  • Notificaciones por correo: EmailJS para envío de códigos de verificación al registrar clientes.

🗄️ Base de Datos NoSQL y Tiempo Real

Cloud Firestore organiza la información en colecciones y documentos flexibles, permitiendo escuchar cambios instantáneos (onSnapshot) entre el portal de clientes y el panel de administración.

  • Colecciones principales: usuarios, mascotas, citas, mensajes y config.
  • Control de roles: Separación lógica entre administrador (dueño) y clientes registrados.
  • Disponibilidad horaria: Validación dinámica de turnos según citas confirmadas.

🎯 Justificación del Sistema

Centralizar el registro de mascotas, la solicitud de citas médicas y la mensajería directa reduce tiempos de espera, evita choques de horarios confirmados y mantiene el historial de consultas ordenado y accesible desde cualquier dispositivo.
